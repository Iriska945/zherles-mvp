# Teamwork Project Prompt

Создание MVP "ЖЕРЛЕС" — платформы для кросс-маркетинга локальных оффлайн-бизнесов. Продукт позволяет заведениям объединяться, запускать совместные акции и обмениваться клиентами через QR-коды и шеринг в мессенджерах (без установки приложений).

Working directory: ~/teamwork_projects/zherles_mvp
Integrity mode: benchmark

## Requirements

### R1. Модуль B2B (Онбординг, Каталог и Дашборд)
- Реализовать страницу онбординга (сбор данных о бизнесе: тип, район, чек).
- Реализовать каталог инструментов и дашборд с фильтрами, рекомендациями и таблицей CRM (содержащей тестовых клиентов).
- Реализовать админ-панель для базового CRUD шаблонов.

### R2. Модуль создания кампаний (Көрші-маршрут)
- Пошаговый интерфейс выбора партнеров.
- Настройка условий (награды, срок действия).
- Предпросмотр клиентского сообщения и генерация QR-кода кампании.

### R3. Модуль B2C (Путь клиента)
- Адаптивный под мобильные устройства интерфейс "Паспорта района" (открывается по QR).
- Механика приглашения друга через share-ссылки для WhatsApp/Telegram.
- Механика погашения бонуса (ввод 4-значного одноразового кода). Повторное погашение должно блокироваться.

### R4. Архитектура и хранение данных
- Использовать Next.js (App Router), TypeScript, Tailwind CSS, Recharts.
- Использовать моковые данные (seed JSON) и Local Storage браузера для сохранения состояния (полноценный бэкенд не требуется).
- Должны присутствовать кнопки для сброса демо-данных.

## Acceptance Criteria

### Функциональность и Верификация (Programmatic)
- [ ] Разработаны E2E тесты на Playwright для проверки ключевых сценариев: создание кампании, симуляция клиента, погашение бонуса.
- [ ] Все E2E тесты проходят успешно (`npx playwright test`).
- [ ] Данные (созданные кампании, погашенные бонусы) сохраняются при перезагрузке страницы (проверяется тестами).
- [ ] Невозможно повторно погасить уже использованный бонус (проверяется тестами).
- [ ] Присутствует кнопка сброса состояния (Reset Demo) для проведения чистого показа жюри.

### UX/UI
- [ ] Клиентский путь (B2C) корректно отображается и работает на мобильном экране.
- [ ] Кабинет бизнеса (B2B) оптимизирован для десктопа.
